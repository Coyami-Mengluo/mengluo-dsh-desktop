# Documentation screenshots

These images show the client's own settings page in development version **0.5.6 (unreleased)**, rendered with isolated demonstration fixtures. Plugin names, versions, counts and status data are fictional. They are not captures of a user's profile, evidence of live service availability, or a reproduction of the official Harness conversation UI.

Before adding or replacing a screenshot, inspect both its visible content and PNG metadata. Do not include credentials, private paths, conversations, real plugin configuration or personal repository names. The source preflight accepts only the exact reviewed images and SHA-256 digests listed in [documentation-assets.mjs](../../scripts/documentation-assets.mjs). Images are copied from the fixture output without editing their pixels.

The application illustration visible inside the settings page retains the separate terms in [the artwork notice](../../assets/ARTWORK.md).
